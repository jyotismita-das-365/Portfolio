Task Manager API

A backend-focused project for creating, organizing, and tracking tasks with secure authentication, clean REST endpoints, and predictable request/response behavior.

Node.js Express MongoDB JWT REST API

route Project Overview

Use Case

Users need a reliable way to create tasks, update progress, and keep data private to their own account.

Implementation

Built an API with user auth, protected routes, structured errors, and validation to keep data consistent and secure.

star Key Features

  • JWT authentication for secure user sessions.
  • CRUD endpoints for task lifecycle management.
  • Status and priority updates with validation checks.
  • User-specific data isolation and access control.
  • Consistent JSON responses for frontend integration.
